# Prossnum Web Application

This directory contains the main Next.js web application for the Prossnum Progress Dashboard.

For the full project overview, including architectural details and developer setup, please refer to the [Main README](../README.md).

## Quick Start (Web App)

1. **Install**: `npm install`
2. **Setup**: Create `.env.local` using the template defined in the root documentation.
3. **Develop**: `npm run dev`
4. **Build**: `npm run build`

## Architecture Highlights
- **Framework**: Next.js 16.1.6
- **Database**: Supabase
- **UI System**: Tailwind v4 + Radix UI
- **Mapping**: MapLibre GL / Leaflet
- **Resilience**: Zero-Restart Dynamic Switcher + Microsoft 365 SMTP Fallback
